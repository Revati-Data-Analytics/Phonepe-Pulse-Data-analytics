# PhonePe Pulse Data Analytics Dashboard

## Project Overview
This project focuses on analyzing digital payment transactions and registered users across India using PhonePe Pulse data.

An interactive Power BI dashboard was developed to explore transaction trends, user growth, state-wise performance, and geographical distribution.

## Project Objectives
- Analyze digital payment transaction trends.
- Understand year-wise and quarter-wise transaction growth.
- Identify top-performing states and districts.
- Analyze registered users and mobile brand distribution.
- Generate meaningful business insights for decision-making.

## Tools & Technologies
- **Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.
- **GitHub** – Project documentation and portfolio hosting.

## Data Processing & Cleaning
The PhonePe Pulse dataset was collected from the official GitHub repository.

The following activities were performed:
- Data extraction and transformation.
- Handling missing and duplicate records.
- Cleaning state and transaction type names.
- Correcting data types.
- Creating relationships between data tables.
- Developing calculated measures using DAX.
